# Rencontres de bataille

`build.py` écrit `data/rencontres.json`, importé par le MJ dans le compendium du monde
« Pendragon — Rencontres de bataille » (augmentez `VERSION` pour forcer la mise à jour).

Seules les valeurs de jeu du Livre du maître (chap. 6) sont reprises : perte et minimum de Moral,
Valeur de chevalier, effectifs par PJ, Gloire, rançon. Les descriptions sont des résumés reformulés
des règles particulières, avec la page du livre. Les adversaires renvoient aux acteurs du compendium
« Pendragon — Adversaires » par leur identifiant fixe.
